# Threaded Web Server in Java

## 📌 Project Overview

This project demonstrates the implementation of a basic web server in Java, including both:
- A **single-threaded server** that handles one client at a time.
- A **multi-threaded (threaded) server** that can handle multiple clients concurrently.

The goal is to illustrate how threading improves server performance and responsiveness in real-world applications.

---

## 🚀 Features

- Accepts multiple client connections
- Uses Java sockets for network communication
- Compares single-threaded vs. multi-threaded server behavior
- Cleanly separates server logic into different classes

---

## 🛠️ Technologies Used

- Java
- Java Socket Programming
- Multithreading
